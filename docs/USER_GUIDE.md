# DocuMind AI: Simple User Guide

## What DocuMind does

DocuMind helps you find information in your files and ask questions about it. It can also search a set of trusted public documents. It shows where an answer came from when a source is available. AI can make mistakes, so check important facts against the original file or official source.

## The words used in the app

- **File:** A PDF, Word document, text file, or photo that you add.
- **Folder:** A place to keep related files, such as one folder for a class, client, or project. Personal folders are private to you.
- **Team:** A shared space for people who work together. A team can have shared folders. The team owner or manager can invite people and choose what they can do.
- **Public documents:** Trusted reference documents available inside DocuMind. These are separate from files you upload. Use them when you want to check a public rule or guide.
- **Chat:** A saved question and answer. Chats stay with the file or folder where you started them.

## Start using DocuMind

1. Sign in with your account. If you are new, create an account and accept the current privacy notice and terms.
2. Open a personal folder or choose a team. Create a folder if you need a new place for your files.
3. Open the folder and add a PDF, Word file, text file, or photo. Clear scans and photos are easier to read.
4. Wait until the file says **Ready**. You can keep using the app while it is being prepared.
5. Type a question in everyday words and send it. You can ask what a file says, request a short summary, or ask about a detail.
6. Check the file names, page numbers, and quoted source text shown with the answer. Open the original file when a detail matters.

## Ask about one file or many

Use the choices above the question box:

- **This file** searches only the selected file.
- **This folder** searches all ready files in the selected folder.
- **Folder + public docs** searches the folder and the public reference documents together.

You do not need to know the exact words in a file. Ask about the idea or describe what you remember. For example: “Find the letter that mentions a payment deadline” or “Which file explains how leave days are counted?”

## Find files and old chats

Choose **Find files or chats** in the chat header. Describe what you remember, even if you do not know the file name or exact words. You can search by a topic, what the file is about, a person or business name, or what you discussed in an old chat.

Results show the full location, such as **Team name / Folder name / File name**. Select a file to open it and ask questions about that file. Select a chat to reopen the saved conversation. Public document results also show their group and a link to the original source.

The chat list shows recent chats. **Find files or chats** can search older chats too. Chats are only shown to people who have permission to read them.

## Personal folders, teams, and public documents

- Use a **personal folder** for your own files.
- Use a **team** when you need to share folders with coworkers, classmates, or other invited people. Team access can be private to one person or shared with the team, depending on the setting shown in the chat.
- Use **public documents** to look through reference material provided in DocuMind. You do not add or change those documents yourself.

You do not need to create a team to use personal folders or public documents.

## Other tools

- **Important dates** shows dates found in your files and reminders you can review.
- **Business tools** can explain a tax letter, check a tender, read a receipt, and compare a payroll file with rates entered by an administrator.
- **Plan and billing** shows available plans, payments, and team seats when they apply.
- **Account settings** has language, WhatsApp, privacy, account download, and sign-out options.

These tools can miss details. Review their results before you act, especially for tax, legal, pay, and payment matters.

## Privacy and safe use

Only upload files you are allowed to use. When you ask a question, relevant file text may be sent to the AI service so it can prepare an answer. Do not add sensitive information unless your team allows this. Sign out on a shared device.

## If something does not work

- If a file is still being prepared, wait a little and refresh the file list.
- If a scan cannot be read, try a clearer photo or a text-based copy.
- If a file or chat does not appear in search, check that you have access to its folder and that the file is ready.
- If an answer is unclear, ask a shorter question or choose **This file** or **This folder** to narrow the search.
- If the app shows an error, refresh the page and try again. Contact your team owner or support if it continues.
